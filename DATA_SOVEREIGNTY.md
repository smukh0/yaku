# Data Sovereignty

- Yaku runs **entirely offline**. It makes no network calls and uploads nothing. Any change that adds telemetry, cloud sync or third-party data sharing will be rejected.
- Any real data a community collects (soil, flow, hydrology, locations) **belongs to that community**. Contributors must never commit real community data to this repository without that community's explicit, documented consent.
- Sacred or sensitive sites and precise locations should not be stored in this repo or in issues.
- Decisions about how data is used belong to the community's own governance (e.g. its Assembly).

Yaku follows the spirit of the [CARE Principles for Indigenous Data Governance](https://www.gida-global.org/care): **C**ollective benefit, **A**uthority to control, **R**esponsibility, **E**thics.
