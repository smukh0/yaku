# Contributor Covenant Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which is incorporated here by reference.

In short: we pledge to make participation a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity, experience, nationality, appearance, race, religion, or sexual identity and orientation. We welcome respectful, constructive behaviour and do not tolerate harassment, insults, personal attacks, or publishing others' private information.

Maintainers may remove, edit or reject contributions that violate this code and may temporarily or permanently ban offenders. Report concerns to the maintainer via the contact on their GitHub profile.
