# Contributing to Yaku

Thanks for helping! Be kind: see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

1. Look for issues labelled `good first issue`, or open one to discuss your idea first.
2. Fork, create a branch, make a focused change.
3. Set up: `pip install -e ".[dev]"`, then run `pytest`. All tests must pass; add tests for new behaviour.
4. Keep the core standard-library only and offline (see [DATA_SOVEREIGNTY.md](DATA_SOVEREIGNTY.md)).
5. Open a pull request describing what and why. Small PRs are reviewed fastest.

Never include real community data. Respect local knowledge: suggestions about a community's practices should come from or with that community.
